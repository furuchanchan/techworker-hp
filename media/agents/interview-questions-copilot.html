求人票から面接の質問を作るエージェント

求人票を貼ると、必須要件と歓迎要件ごとに面接の質問と深掘りの質問を下書きします。よい回答の目安もそろうので、面接官ごとの聞き方の差を小さくできます。

01できること

これまで
  • 面接官がそれぞれ自分で質問を考えるので、候補者ごとに聞く内容がばらつきます。
  • 求人票の要件と面接の質問が結びついておらず、面接後の評価がしにくくなっています。
  • 初めて面接を担当する社員が、何をどう聞けばよいかを人事に相談しています。
このエージェントを使うと
  • 求人票を貼るだけで、要件ごとの質問と深掘りの質問が下書きされます。
  • よい回答の目安がつくので、面接官どうしで評価の物差しをそろえやすくなります。
  • 聞いてはいけない質問の一覧を指示文に入れるので、下書きの段階で避けやすくなります。
  • 人事は下書きを直して面接官に渡すところに時間を使えます。

02仕組み

エージェントが何を受け取り、何を見て、何を返すか。最後に人が確かめるところまでを1枚にしています。

受け取るもの

求人票の本文（職務内容、必須要件、歓迎要件）、等級、面接の回（一次面接か最終面接か）

エージェント

Microsoft 365 Copilot　エージェント ビルダー

指示文

役割と進め方、答え方を決める（04 指示文）

渡す資料
  • 当社の評価項目と評価の物差し（Word）
  • 面接で聞いてはいけない質問の一覧（社内の採用ガイド）
  • 職種別の質問集（応募者の個人情報を消したもの）
つなぐ道具
  • なし（つなぐ道具は使いません）
返すもの

要件ごとの質問、深掘りの質問、よい回答の目安、面接官への注意点

人が確かめる

どの質問を使うかと評価の物差しは、人事と面接官が決めます。

03作り方

  1. 1

    テンプレートから始める

    Microsoft 365 Copilot の左側のウィンドウで「新しいエージェント」を選びます。「テンプレートで開始」から「面接の質問アシスタント」を選びます。説明と指示と推奨プロンプトが入った状態で編集が始まります。

  2. 2

    名前と説明を入れる

    「構成」タブを開き、「名前」に「面接質問の下書き（人事）」のような30文字以内の名前を入れます。「説明」には、面接官が求人票から質問を作るためのエージェントであることを書きます。

  3. 3

    指示を貼る

    「指示」にこのページの指示文を貼ります。評価項目の名前を、当社の評価シートで使っている言葉に書き換えます。

  4. 4

    評価項目と採用ガイドをナレッジに入れる

    「ナレッジ」の欄で、SharePoint の採用フォルダーにある評価項目と採用ガイドを選びます。応募者の履歴書や面接の記録は入れません。

  5. 5

    「試してみる」で確かめる

    「試してみる」タブで、過去の求人票を2〜3件貼って質問を作らせます。人事の担当者が下書きを読み、聞いてはいけない質問が混ざっていないかを確かめます。

  6. 6

    作成して面接官と共有する

    「作成」を選んだあと、「共有」を開きます。面接官のグループを「チャット可能」で追加します。指示文を直す人事の担当者は、1人ずつ「編集可能」で追加します。

04指示文（そのまま貼れます）

エージェント ビルダーの「構成」タブにある「指示」欄（8,000文字まで）に貼ります。［　］のところは自社の言葉に置き換えてください。

指示文 — Microsoft 365 Copilot エージェント ビルダー
# 役割
あなたは当社の人事部で、面接の準備を手伝う担当です。求人票をもとに、面接官が使う質問の下書きを作ります。

# 受け取るもの
- 求人票の本文（職務内容、必須要件、歓迎要件）
- 等級や役職
- 面接の回（一次面接、二次面接、最終面接）

# 進め方
1. 求人票から、必須要件と歓迎要件を1つずつ抜き出します。
2. ナレッジにある当社の評価項目と結びつけます。
3. 要件ごとに、過去の行動を聞く質問を1つ作ります。
4. 答えを深く聞くための深掘りの質問を2つ作ります。
5. 等級と面接の回に合わせて、質問の難しさを変えます。
6. 最後に、聞いてはいけない質問が混ざっていないかを、採用ガイドの一覧と照らし合わせます。

# 答え方
要件ごとに、次の形で書きます。
- 要件：求人票の文言をそのまま書きます。
- 評価項目：当社の評価項目の名前を書きます。
- 質問：候補者に聞く質問を1文で書きます。
- 深掘りの質問：2つ書きます。
- よい回答の目安：具体的な行動や結果が語られているかの目安を、2〜3行で書きます。
- 面接官への注意：聞き方で気をつける点を1行で書きます。
最後に、面接の時間配分の目安を書きます。文末は「です」「ます」にします。

# 根拠の示し方
- 評価項目と採用ガイドを使った箇所には、資料名を添えます。
- 求人票に書いていない要件を足したときは、「求人票に記載なし」と書き添えます。

# わからないときの返し方
- 求人票の要件があいまいなときは、下書きの前に、確かめたい点を3つまで質問します。
- 評価項目に当てはまらない要件には、「評価項目の追加を人事で検討」と書きます。

# させないこと
- 本籍、出生地、家族、住まい、宗教、支持政党、思想、尊敬する人物、愛読書など、本人の適性や能力と関係のない事柄を聞く質問を作りません。
- 年齢、性別、結婚や出産の予定を聞く質問を作りません。
- 応募者の名前や経歴などの個人情報は受け取りません。書かれたときは、その部分を使いません。
- 合否や点数を判断しません。

05管理者が先に決めること

使い始める前に、Microsoft 365 Copilot の管理者が決めておく設定です。ここを決めてから配ると、情報の扱いで止まりにくくなります。

ナレッジに入れてよい資料の範囲

このテンプレートの注意書きでは、個人情報や機密情報の扱いは利用する会社の責任とされています。応募者の履歴書や面接の記録はナレッジに入れない、と先に決めておきます。

共有の範囲

共有ダイアログで面接官のグループを「チャット可能」で追加し、「チャット アクセスの組織全体で共有する」はオンにしません。組織全体へ共有できる人は、Microsoft 365 管理センターの「エージェント」の「設定」にある「共有」で決められます。

面接官のライセンス

共有された人はエージェントに設定した機能に合うライセンスを持っていないと使えません。面接官全員が Microsoft 365 Copilot ライセンスか従量課金制の対象になっているかを、共有の前に確かめます。

エージェント フィードバックの共有

Microsoft 365 管理センターの「エージェント」の「設定」にある「エージェント フィードバックの共有」で、利用者の評価やコメントを作成者が受け取れるかを決めます。人事が質問の出来を直せるよう、このエージェントを「選択されたエージェント」に入れておきます。

ライセンスと課金の方式

Microsoft 365 Copilot ライセンス、または Copilot Studio の従量課金制（Copilot クレジット）を有効にしたテナントが要ります。当社の評価項目や採用ガイドを SharePoint やアップロードしたファイルから読ませるには、このどちらかが必要です。

06人が確かめるところ

  • 応募者の名前や履歴書の内容は、エージェントに貼りません。
  • 下書きの質問は、人事の担当者が採用ガイドと照らし合わせてから面接官に渡します。
  • 合否や評価の判断はエージェントに任せず、面接官と人事が決めます。

07うまくいかないとき

どの職種でも似た質問ばかり出る

求人票の必須要件を箇条書きにして貼ります。指示文の評価項目を当社の言葉に書き換え、職種別の質問集をナレッジに足します。

家族や出身地に触れる質問が混ざる

聞いてはいけない質問の一覧をナレッジに入れ、指示文の「させないこと」にも同じ項目を書きます。混ざった例を「試してみる」で再現し、直ったかを確かめます。

一次面接と最終面接で同じ深さの質問になる

このテンプレートは役職のレベルに合わせて質問の難しさを変えられます。スターター プロンプトの文面に、面接の回と等級を書く欄を入れておきます。

0830日後に測ること

使われているか、どれだけ時間が浮いたか、出来は十分か。使い始めて30日後に、次の点を確かめます。

使われているか：面接の前に使った面接官の数

Microsoft 365 管理センターの「レポート」から「使用状況」を開き、「Microsoft Copilot」の「エージェント」を選びます（プレビュー）。このエージェントのアクティブ ユーザー数を、30日間に面接を担当した面接官の人数と比べます。

時間：面接官に質問を渡すまでの時間

求人票を受け取ってから、面接官に質問を渡すまでの時間を記録します。使い始める前の5件と、使い始めた後の5件で比べます。

出来：手直しなしで使えた質問の割合

人事の担当者が下書きの質問を「そのまま使う」「直して使う」「使わない」に分けて数えます。「使わない」の理由を書き残し、指示文の直しに使います。

09広げ方

  • 社内公募や異動の面談で使う質問を作る版
  • 新しく面接官になる社員の練習相手として、質問の作り方を教える版
  • インターンシップの選考で使う質問を作る版
