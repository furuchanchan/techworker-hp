非エンジニアのClaude Code活用｜業務部門で何ができるか

Claude Codeは、最初の1週間で定型業務を1本仕上げるところから、非エンジニアでも始められます。
営業・経理・人事・マーケなどの業務部門に、Claude Codeを広げたい担当者の方に向けた記事です。
職種別ユースケース、安全な練習台、最初の1週間、つまずきの対処、研修の設計が分かります。

非エンジニアでも、Claude Codeは使えますか？

ファイルと手順がある業務なら、日本語の指示で完了まで任せられるため、職種を問わず使えます。

Claude Codeは、ファイルを読み、編集し、コマンドを実行するエージェント型のツールです。AIが複数の手順を、完了まで自分で進めます。

名前と「CLI（コマンドライン）」という言葉が、2つの誤解を生んでいます。

  • Codeと付くから、プログラマー専用だろうという誤解。
  • 黒い画面にコマンドを打てないと、使えないという誤解。

どちらも、2026年時点では成り立ちません。Anthropic公式ドキュメント（2026年7月時点）では、利用画面にデスクトップアプリ・ブラウザ・IDE拡張が提供されています。指示は、日本語の文章です。「このフォルダのCSVを読んで、部署別に集計した表を作って」と書けば、指示になります。

すでに使っているチャットAIとの差は、ファイルを直接扱い、完了まで進めることです。

  • やりとり：チャットAIは1問1答で、結果は人が持ち帰ります。Claude Codeは、指示を受けると複数の手順を自走します。
  • ファイル：チャットAIは1つずつ添付します。Claude Codeは、フォルダごと読み書きし、成果物をファイルで残します。
  • 業務との距離：チャットAIは相談相手です。Claude Codeは、手を動かして作業を終わらせる担当者です。

たとえば、10個のCSVを1つに統合し、月別の集計表とコメントを付ける作業があります。Claude Codeなら、フォルダを指定して指示を1回書けば、結果をファイルで返します。MCPという仕組みで、Google DriveやSlack、Jiraなどの業務ツールとも接続できます（2026年7月時点）。

コードを書くかどうかは、本題ではありません。ファイルのある定型業務を任せられるかどうかが、本題です。

任せる業務の範囲を決める方法は、AIに任せる業務の決め方（業務図ラボ）で扱っています。

TechWorkerは、Claude Codeを何に使っていますか？

代表の古野が毎日使い、開発のほか、営業資料の作成や毎朝の自動の集計にも使っています。

TechWorkerでは、代表の古野が毎日Claude Codeを使っています。用途は、次のとおりです。

  • 自社サービスの開発。
  • メディアの改修。
  • 営業資料の作成。
  • 毎朝の自動の集計。

営業資料の作成と毎朝の自動の集計は、ファイルと手順がある業務です。この記事で扱う定型業務と、同じ型にあたります。

業務部門は、どんな手順で始めればよいですか？

環境、安全な練習台、最初の1本、1週間の進め方、確認の型の5つを、順に整えて始めます。

手順1　環境を用意する

公式ドキュメントによれば、Claude Codeの利用にはClaudeの有料サブスクリプションなどが前提です（2026年7月時点）。非エンジニアは、デスクトップアプリかブラウザ版から始めるのが現実的です。ターミナルの操作は不要です。

会社のPCで使う場合は、先に情報システム部門へ、利用可否とデータの扱いを確認します。プランと費用感は、Claude Codeのコストの記事で整理しています。

手順2　安全な練習台を作る

デスクトップに「AI練習」フォルダを1つ作り、コピーしたファイルだけを入れます。原本、機密情報、個人情報は置きません。練習中に何が起きても、コピーしか影響を受けない状態にします。

手順3　最初の1本を決める

毎週くり返している定型作業を、1つ選びます。選ぶ基準は、一番くり返している業務です。一番困っている業務は、後回しにします。頻度の高い作業ほど効果を実感しやすく、翌週からそのまま使い続けられます。

手順4　最初の1週間で回す

  • 1日目：環境を用意し、練習フォルダの中身を説明させます。日本語で指示すれば動くことを体感します。
  • 2日目：コピーしたファイル群を、条件を決めて整理・リネームさせます。
  • 3日目：自分の業務ファイル（コピー）を1つ渡し、要約・整形させます。
  • 4日目：同じ作業を、指示の書き方を変えて2〜3回やり直します。指示が具体的なほど、出力が変わります。
  • 5日目：決めておいた定型業務を、成果物まで1本仕上げます。
  • 週末：かかった時間と品質をメモし、チームに共有します。続けるか、広げるかの判断材料になります。

手順5　AIが下書き、人が確認して仕上げる

基本の型は、4手です。手元のファイルを渡し、指示を書き、成果物をファイルで受け取り、人が確認して仕上げます。

AIの出力を、そのまま社外や経営層に出してはいけません。事実の取り違え（ハルシネーション）はゼロにならないためです。この型を守れば、確認込みでも、従来より短い時間で成果物にたどり着けます。

業務部門の導入は、どこでつまずきますか？

指示が曖昧、許可の確認で止まる、元ファイルを上書き、機密の判断で止まる、の4つが代表例です。

つまずきの大半は、指示とルールの問題です。技術の問題は少数です。

  • 指示が曖昧。想定と違う成果物が返ってきます。「目的・対象ファイル・完成形」の3点を書きます。見本があれば、見本ごと渡します。
  • 許可の確認で戸惑う。「この操作を許可しますか」で手が止まります。何をしようとしているかを読んで、判断します。意味が分からない操作は、拒否してかまいません。拒否しても壊れません。
  • 元ファイルの上書き。練習フォルダとコピーの運用を徹底します。指示に「元ファイルは変えず、新しいファイルで出力して」と入れます。
  • 長い作業の迷走。手順が多い指示は、途中でずれます。作業を小さく区切り、途中の成果物を確認してから次の指示を出します。
  • 機密データの扱い。入れてよいか判断できず、止まります。社内ルールの確認を先に済ませます。判断がつくまでは、ダミーデータで練習します。

一発で完璧な出力を求めないことも、心構えになります。部下に仕事を頼むのに似ています。成果物を見て、直す点を伝え、もう一度やらせます。この往復を前提にすると、指示のハードルが下がります。

もう1つの失敗は、エンジニア向けの教材や展開手順を、業務部門にそのまま流用することです。立ち上げの設計は、別物だからです。

  • 目的：エンジニアは開発生産性の向上です。業務部門は、資料作成・集計・定型業務の時間削減です。
  • 前提知識：エンジニアはGit・ターミナル・開発環境です。業務部門は、フォルダとファイルが分かれば足ります。
  • 最初の課題：エンジニアは実コードの改修です。業務部門は、自分の業務ファイル（コピー）での成果物づくりです。

部門を越えて広げるときの体制づくりは、Claude Codeの社内展開の記事で扱っています。

職種ごとに、どんな業務を任せられますか？

営業のリサーチ、経理の集計、人事の書類整理、マーケのレポートなど、集める・整える・作る定型業務です。

下表は、任せられる業務と成果物のイメージです。いずれも例であり、実際に扱えるかどうかは、自社のデータ取り扱いルールが前提です。

営業商談前の企業リサーチまとめ訪問先リスト（CSV）1社1枚の商談準備メモ
議事録の整形とCRM入力用サマリー商談メモ・文字起こし要点と次アクションの一覧

よくある質問

プログラミング経験がまったくなくても、Claude Codeは使えますか？

使えます。指示は日本語の文章で書けて、プログラミング言語の知識は前提になりません。ただし「目的・対象ファイル・完成形」を伝える指示の型と、出力を人が確認してから使う運用は必要です。最初は練習用フォルダとコピーしたファイルで小さく始めてください。

黒い画面（ターミナル）を使えないと始められませんか？

ターミナルは必須ではありません。Anthropic公式ドキュメントでは、デスクトップアプリ・ブラウザ・IDE拡張でも利用できると案内されています（2026年7月時点）。非エンジニアはデスクトップアプリかブラウザから始めるのが現実的です。

会社の機密情報や個人情報を入れても大丈夫ですか？

自社のルール確認が先です。データの取り扱い条件は契約プランや社内規程によって変わるため、情報システム部門や法務に確認してから使います。練習段階では、機密・個人情報を含まないコピーやダミーデータだけを置いた専用フォルダで試すのが安全です。

ChatGPTなどのチャットAIと何が違うのですか？

チャットAIは質問に答えを返す対話相手で、結果は人がコピーして持ち帰ります。Claude Codeは、フォルダの中のファイルを直接読み書きします。複数の手順を完了まで自走し、成果物をファイルで残すAIエージェントです。定型業務を丸ごと任せるならClaude Codeが向きます。

研修で学ぶ場合は、何をどう設計しますか？

ユースケースの棚卸し、環境の準備、実務ファイルのハンズオン、定着伴走の4段階で設計します。

独学でも始められます。部門単位でそろって立ち上げるなら、研修の形が速く確実です。

  1. 職種別ユースケースの棚卸し。受講者の実際の業務から、くり返しているファイル作業を洗い出し、職種ごとの題材を決めます。
  2. 安全な環境の準備。利用プラン、データの取り扱いルール、練習用フォルダを、情報システム部門と合意した状態で当日を迎えます。
  3. 実務ファイルでのハンズオン。指示の型（目的・対象ファイル・完成形）と確認の型を教えます。その場で、業務ファイル（コピー）から成果物を1本作ります。
  4. 定着伴走。研修後の2〜4週間、つまずきの解消と職種別の型の追加を伴走します。

TechWorkerのClaude Code研修も、この4段階で設計しています。上場企業を含む37社・2,500名の生成AI支援で見えているのは、自分の業務で1本仕上げた経験が定着を決めることです。

研修内容・費用は、お問い合わせください。詳細はClaude Code研修のご案内をご覧ください。法人向け研修は、人材開発支援助成金の対象となり得ます。要件・申請可否は、管轄労働局または社労士にご確認ください。
