CompanyMap AI / Docs

進め方

進め方と分担

業務図をつくって任せる仕事を決めるところまでをCompanyMap AIが、構築・導入・効果の確認を実装担当（FDE）が進めます。お客さまにお願いするのは、聞き取りに答えることと、変える仕事を決めることの2つです。

全体の流れ

  1. 対象業務の選定（最初の2週間）業務の情報を集めて業務図にし、詰まり・かかる時間・AIに任せられる作業を並べて、最初に任せる作業を決めます。→ 最初の2週間
  2. 構築決めた作業に、AIやツールを組み込みます。業務図から、作業の手順・守るルール・AIにさせないことを取り出して、仕様にします。
  3. 導入現場の方に使い方を説明し、運用を始めます。見直した後の業務図を、新しい版として残します。
  4. 効果検証使われた回数と人が直した時間を毎月記録し、浮いた時間を確かめます。振り返りの中で、次に任せる作業を提案します。そのあと続けるかどうかは、下の「構築のあとの3つの進み方」からお選びいただけます。

構築・導入・効果検証は、対象の業務ごとに進めます。構築に進むかどうかは、業務図を見てから決めていただけます。業務の整理だけのご依頼も承ります。

構築のあとの3つの進み方

構築・導入が終わったところで、次の3つからお選びいただけます。ご契約の前に決めておく必要はありません。どれを選んでも、作った仕組みはお客さまの環境で動き続けます。

進み方 TechWorkerがすること お客さまがすること 向いている場合
1. 自社で回す（ここで終了） 業務図・手順書・作った仕組み・記録・お預かりした資料をそろえてお渡しし、終わります。引き渡しの後、ご契約で決めた期間は、弊社の作った物の誤りを無償で直します。 単価や締め日などの値は、表で直します（お客さまが直せる形で作ります）。計算の形を変えたいときは、その都度ご相談ください。 担い手が決まっていて、取引先や決まりがあまり変わらない
2. TechWorkerが動かし続ける（年のご契約） 毎月の点検、人・取引先・システムが変わったときの直し、業務図の更新、月1回の振り返りと効果の記録、決めた数の作業の追加を行います。 月1回の振り返りに出て、変わったことを伝えます。 取引先や決まりがよく変わる。次の作業もAIに任せたい
3. 次の部署へ広げる 同じ進め方で、次の部署の業務図から構築・導入まで進めます。 次の部署の窓口の方を決めます。 ほかにも、1人に頼っている部署がある
  • 2と3は組み合わせられます。1を選んだ後でも、2・3に移れます。業務図は、お渡しした版から始めます。
  • 年のご契約は1年ごとです。終えるときも、1と同じ物をそろえてお渡しします。

だれが、何をするか

段階 CompanyMap AI（製品） 実装担当（FDE） お客さま
対象業務の選定 担当者に質問し、資料と履歴を読んで、業務図の下書きを作ります。詰まりと時間の一覧、AIに任せる順番を出します。 だれに何を聞くかを決め、図を現場の方と確かめます。候補を絞ります。 担当者が聞き取りに答えます。最初に任せる作業を選びます。
構築 業務図から、作業ごとの手順書（AIの作業手順・守るルール・AIにさせないこと）を書き出します。 AIとツールを組み込み、試します。 試す人を決めます。
導入 見直す前と見直した後の業務図を、版として並べて残します。 現場の方に説明し、運用を始めます。 現場で使います。
効果検証 入力した回数と時間から、浮いた時間を毎月計算します。 毎月振り返り、次の候補を提案します。役員向けの1枚にまとめます。 役員に報告します。

お客さまにお願いすること

お客さまにお願いするのは、聞き取りに答えることと、変える仕事を決めることの2つです。

  • 窓口の方（1名）：対象の業務を一緒に決め、聞き取りの案内を答える方に配っていただきます。案内のリンクと文面は、こちらでご用意します。
  • 聞き取りに答える方：その業務の担当者とベテランの方です。1人15分ほど、声か文字で答えます。
  • 決める方：業務図と改善候補の一覧を見て、最初に任せる作業を選んでいただきます。

構築に進んだあとは、試す人を決め、現場で使い、社内に報告していただきます。

聞き取りの設計はTechWorkerが行います

だれに、何を、どの順で聞くかは、実装担当が決めます。お客さまに聞き取りの画面を設計していただく必要はありません。お客さまの画面では、業務図とAIに任せる順番をご覧いただけます。詳しくはお渡しするものをご覧ください。
