## 2026年10月7日

- 3つの情報（聞き取り・資料・業務の記録）からAIが業務図を作ることと、お客さまにお願いする3つ（聞き取りの案内を配る・1人15分ほど答える・AIが作った図を確かめて任せる仕事を決める）を、各ページで書きそろえました。業務システムの履歴はCSVなどで共有いただければAIが資料として読むこと、AIが最初の下書きを作ることも、業務の情報の集め方・いまの提供範囲・データの取り扱いに書きました。
- 進め方と分担に「構築のあとの3つの進み方」（自社で回す／TechWorkerが動かし続ける／次の部署へ広げる）を載せました。よくある質問に「構築のあと、契約はずっと続きますか」を足しました。
- データの取り扱いに、契約の終了時の削除の手順を載せました。聞き取りの録音・書き起こし・答えも、業務図などと一緒に会社ごとまとめて削除します。
- 聞き取りの録音・書き起こし・答えの保存先を「Cloudflare R2」に直しました（「R2 と D1」と書いていましたが、D1 は使っていません）。
- CompanyMap AI Docs を公開しました。
- 聞き取りの同意画面に、答えを見る人（TechWorkerの担当者。依頼企業には名前を伏せた回答の一部を業務図の根拠としてお見せすること）と、使い道（業務図づくり。人事評価には使わないこと）を示すようにしました。
