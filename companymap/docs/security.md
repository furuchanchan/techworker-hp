## まとめ

| 項目 | いまの仕様 |
|---|---|
| ログイン | ご招待した方だけ。メールアドレスに届く確認コードでログインします（Cloudflare Access）。 |
| 会社ごとの区切り | すべての画面と通信で、ご自身の会社の情報かを確かめます。他社の情報は見られません。 |
| 操作の記録 | 画面を開いた操作と、変更・削除の操作を記録します。 |
| 保存先 | Cloudflareのデータベースとストレージ。日本国内に限る設定はしていません。 |
| 使うAI | Anthropic の Claude と、Cloudflare の Workers AI。AIは直し方を提案するだけで、業務図を変えるのは人です。 |
| 聞き取り | 名前・連絡先・部署は聞きません。会話は録音し、書き起こしと分析に使います。 |
| 削除 | 業務図・資料・操作の記録は、ご契約の終了時に削除します。聞き取りの録音・書き起こしの保管期間は、ご契約で決めます。 |

## 保存する情報と場所

| 情報 | 保存する場所 | 保存しないもの |
|---|---|---|
| 業務図、資料の本文、コメント、操作の記録 | Cloudflare D1（データベース） | — |
| Excelの点検 | Cloudflare D1。ブック名、シート名、数式の形（中の文字は印に置き換え）、エラーの位置、マクロの名前、点検の結果 | ファイル本体、セルの値、マクロのコード、パスワード |
| Excelの入力チェック | 保存しません（お使いのブラウザの中だけで調べます） | 調べた値、条件、結果 |
| 聞き取りの録音・書き起こし・答え | 聞き取りの基盤 CoeSignal（Cloudflare R2） | 名前、連絡先、部署 |

保存する地域を日本国内に限る設定は、いまはしていません。日本国内だけでの保存が必要なときは、個別にご相談ください。

## 見られる人

- **業務図の画面**：お客さまがご招待した方と、TechWorkerの担当者です。メールアドレスに届く確認コードでログインし、すべての通信でログインを確かめます。
- **権限**：「編集できる」と「提案だけ」があります。提案だけの方は、図に直接手を入れられず、直し方の提案とコメントだけを残せます。
- **聞き取りの答え**：答えそのものを見るのは、TechWorkerの担当者（品質の確認を含む）です。お客さまの画面には、一人ひとりの答えは出しません。業務図の作業ごとに、根拠として「何人中何人がこう答えたか」を示します。

## 操作の記録

- 画面を開いた操作と、変更・削除の操作について、日時、アカウント、会社、操作の種類を記録します。書いた本文は記録しません。
- お客さまの編集できる方は、自社の記録をCSVで書き出せます（既定は直近90日）。

## AIの使い方

| 使う場面 | AI | 経路 |
|---|---|---|
| 資料からの業務図の下書き、直し方の提案 | Anthropic Claude | Cloudflare AI Gateway を経由 |
| 聞き取りの質問と聞き返し | Anthropic Claude | 聞き取りの基盤 CoeSignal から |
| 聞き取りの書き起こし | Cloudflare Workers AI（音声の文字起こし） | Cloudflare の中 |
| 他社事例の検索の並べ替え | Cloudflare Workers AI | Cloudflare の中 |

- AIは、業務図の直し方を提案するだけです。業務図を変えるのは人です。
- AIの提供会社は、法人向けの規約で、送った内容を自社のAIの学習に使わないとしています。

## 保管と削除

- **業務図、資料、コメント、操作の記録、Excelの点検の結果**：ご契約の終了時に、会社の情報をまとめて削除します。削除したことは記録に残します。
- **聞き取りの録音・書き起こし・答え**：保管の期間と削除の時期は、ご契約で決めます。答える方の画面にも、そのことを示しています。

## 聞き取りの同意と匿名の扱い

- 答える方には、最初の画面で、実施する会社、答えを見る人、保管の期間、問い合わせの窓口を示し、同意を得てから始めます。
- 名前・連絡先・部署は聞きません。同じ役割の方が5人未満のときは、役割を伏せて、ほかの答えとまとめます。
- 答えの中身から、だれの答えか推測できてしまうことがあります。そのため「完全な匿名」とはお伝えしていません。
- 聞き取りは業務を図にするためのもので、人事評価には使いません。人事評価や給与、退職の意向などは聞かないように設定しています。

聞き取りの流れは[業務の情報の集め方](/companymap/docs/collecting)をご覧ください。聞き取りの基盤 CoeSignal（TechWorkerが開発・運用）の情報の取り扱いは、[CoeSignal Docs](https://coesignal.techworker.co.jp/docs/security) にも載せています。

## いまは対応していないこと

- SSO（シングルサインオン）
- 日本国内だけでの保存
- 第三者による脆弱性診断の結果のご提出

いずれも、必要なときは個別にご相談ください。対応できるかと、その時期をお伝えします。
