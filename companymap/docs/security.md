## まとめ

| 項目 | いまの仕様 |
|---|---|
| ログイン | 業務図の画面は、ご招待した方だけが使えます。メールアドレスに届く確認コードでログインします（Cloudflare Access）。 |
| 会社ごとの区切り | 画面と通信のたびに、ご自身の会社の情報かを確かめます。ほかのお客さまの情報は見られません。 |
| 操作の記録 | 画面の表示と、変更・削除の操作を記録します。 |
| 保存先 | Cloudflare のデータベース（D1）とストレージ（R2）。保存時も通信時も暗号化されます。日本国内に限る設定はしていません。 |
| 使うAI | Anthropic の Claude と、Cloudflare の Workers AI。AIは資料から業務図の最初の下書きと、工程の説明の空欄を直接書きます。そのあとの変更は提案として出し、業務図に入れるのは人です。 |
| 聞き取り | 名前・連絡先は聞きません。最初の質問で役割を選んでもらいます。会話は録音し、書き起こしと分析に使います。 |
| 削除 | ご契約の終了時に、業務図・資料・操作の記録と、聞き取りの録音・書き起こし・答えを、会社ごとまとめて削除します。聞き取りの保管期間は、ご契約で決めます。 |

## 保存する情報と場所

| 情報 | 保存する場所 | 保存しないもの |
|---|---|---|
| 業務図、資料の本文、コメント、操作の記録 | Cloudflare D1 | — |
| 業務図に取り込んだ聞き取りの答え | Cloudflare D1（回答者の名前を付けない答えの本文と人数。本文に出てくる人名などは、自動では伏せません） | 回答者の名前、連絡先 |
| 聞き取りの録音・書き起こし・答え | 聞き取りの基盤 CoeSignal（Cloudflare R2） | 回答者の名前、連絡先 |
| Excelの点検 | Cloudflare D1。ブック名、シート名、数式の形、エラーの位置、マクロの名前、点検の結果。数式の中の文字は印に置き換えます（数字・関数名・シート名は残ります） | ファイル本体、セルの値、マクロのコード、パスワード |
| Excelの入力チェック | 保存しません（お使いのブラウザの中だけで調べます） | 調べた値、条件、結果 |

- 保存するデータは、保存時に暗号化（AES-256）され、通信も暗号化（TLS）されます（出典：Cloudflare の [D1](https://developers.cloudflare.com/d1/reference/data-security/)・[R2](https://developers.cloudflare.com/r2/reference/data-security/) の説明）。
- 保存する地域を日本国内に限る設定は、いまはしていません。日本国内だけでの保存が必要なときは、個別にご相談ください。

## 見られる人

- **業務図の画面**：お客さまがご招待した方と、TechWorkerの担当者です。メールアドレスに届く確認コードでログインし、画面と通信のたびにログインを確かめます。
- **権限**：「編集できる」と「提案だけ」があります。提案だけの方は、図に直接手を入れられず、直し方の提案とコメントだけを残せます。
- **聞き取りの答え**：答え全体を見るのは、聞き取りを運用するTechWorkerの担当者と品質管理の担当者です。お客さまの画面には、だれが答えたかは出しません。業務図の作業ごとに、根拠として、回答者の名前を付けない答えの一文と「何人中何人がこう答えたか」を示します。

## ログインのいらない入口

次の3つは、ログインなしで開けます。

| 入口 | 中身 | 守り方 |
|---|---|---|
| 聞き取りの答える画面 | 答える方が使う画面 | 推測できない鍵の付いたURL。名前や連絡先の登録はいりません |
| 手順書をAIに読ませる専用のURL | 業務図から書き出した手順書（読むだけ） | 推測できない鍵の付いたURL。実装担当が発行し、いつでも取り消せます。発行と取り消しは記録に残ります |
| 他社事例の検索 | 公開情報から集めた他社の事例 | お客さまの情報は含みません |

## 操作の記録

- 画面の表示と、変更・削除の操作について、日時、アカウント、会社、操作の種類を記録します。書いた本文は記録しません。
- お客さまの編集できる方は、自社の記録をCSVで書き出せます（既定は直近90日）。
- 会社の情報を削除するときは、記録もまとめて消え、削除したことだけを記録に残します。

## AIの使い方

| 使う場面 | AI | 経路 |
|---|---|---|
| 資料からの業務図の下書き、直し方の提案 | Anthropic Claude | Anthropic の API へ直接送ります |
| 聞き取りの質問と聞き返し | Anthropic Claude | 聞き取りの基盤 CoeSignal から |
| 聞き取りの書き起こし | Cloudflare Workers AI（音声の文字起こし） | Cloudflare の中 |
| 他社事例の検索の並べ替え | TypeSafe 社のモデル（Cloudflare 経由で呼び出す第三者のモデル） | 検索の言葉と公開の事例だけを渡します。お客さまの情報は渡しません。Cloudflare の表示では、データを保持しないモデルです |

- AIが業務図を直接書くのは、資料から作る最初の下書きと、工程の説明の空欄だけです。そのあとの変更は、AIが提案として出し、編集できる方が採用したものだけが業務図に入ります。
- Anthropic と Cloudflare は、法人向けの規約で、送った内容をAIの学習に使わないとしています（[Anthropic の規約](https://www.anthropic.com/legal/commercial-terms)、[Cloudflare Workers AI の説明](https://developers.cloudflare.com/workers-ai/platform/data-usage/)）。
- 資料や聞き取りの答えを Claude に渡すとき、内容は米国の Anthropic に送られます。
- Anthropic の API に送った入力と出力は、Anthropic が原則30日以内に削除すると説明しています。規約に反する疑いがあると判定されたものは最長2年、安全のための分類の点数は最長7年残ることがあります（[Anthropic の説明](https://privacy.claude.com/en/articles/7996866)、2026年7月1日更新）。入力を一切保存しない契約（Zero Data Retention）は結んでいません。
- 聞き取りの同意画面では、処理を任せる会社として OpenAI も示しています。聞き取りの基盤 CoeSignal の別の機能で使うためで、CompanyMap AI の聞き取りでは使っていません。

## 保管と削除

- **業務図、資料、コメント、操作の記録、Excelの点検の結果**：ご契約の終了時に、TechWorkerが会社の情報をまとめて削除します。削除の後も、データベースの復元用の履歴には最大30日残ります。
- **AIに送った内容**：削除しても、Anthropic 側に原則30日以内（規約に反する疑いがあると判定されたものは最長2年）残ることがあります。
- **聞き取りの録音・書き起こし・答え**：保管の期間は、ご契約で決めます。答える方の画面にも、そのことを示しています。ご契約の終了時には、業務図などと同じ操作で、その会社の聞き取りをすべて削除します。

### 削除の手順

| 項目 | 内容 |
|---|---|
| 行う人 | TechWorkerの運用担当者 |
| 時期 | ご契約の終了時。会社ごとの削除のご依頼があったときは、その時 |
| 消えるもの | 業務図、資料、コメント、名簿、提案、操作の記録、Excelの点検の結果、聞き取りの設定。聞き取りの基盤 CoeSignal にある、その会社の聞き取りすべての録音・書き起こし・答え・分析 |
| 順番 | 先に聞き取りの基盤から聞き取りを消し、すべて消せたときだけ業務図などを消します。途中で止まったときは、消し終えた聞き取りを飛ばして、残りから続けます |
| 答えている方がいるとき | 答えている途中の方がいる聞き取りは消しません。新しい回答の受け付けを止め、数分後に消し直します |
| 確かめ方 | 削除の画面に、消した件数（聞き取りの本数と答えた人数を含む）が出ます。担当者は、その本数がお客さまの聞き取りの本数と合うかを確かめます |
| 残るもの | 削除したことの記録（日時、会社名、聞き取りの名前、件数）が残ります。この記録に、録音・書き起こし・答えの中身は含みません。このほか、データベースの復元用の履歴に最大30日、Anthropic 側に原則30日以内（規約に反する疑いがあると判定されたものは最長2年）残ることがあります |
| お知らせ | ご依頼があれば、削除した日と件数を書面でお知らせします |

会社を残したまま、聞き取りを1本だけ消すことは、いまはできません。

## 聞き取りの同意と匿名の扱い

- 答える方には、最初の画面で、実施する会社、答えを見る人、使い道（人事評価には使わないこと）、保管の期間、問い合わせの窓口を示し、同意を得てから始めます。
- 名前・連絡先は聞きません。最初の質問で、役割（例：営業、経理・総務）を選んでもらいます。同じ役割の方が5人未満のときは、役割を伏せます。
- 取り込んだ答えは回答者の名前を付けずに保存しますが、答えの本文に出てくる人名などは、自動では伏せません。答えの中身から、だれの答えか推測できてしまうこともあります。そのため「完全な匿名」とはお伝えしていません。
- 聞き取りの答えは、業務図をつくるために使います。人事評価には使いません。人事評価や給与、退職の意向などは、聞き取りの質問に入れません。

聞き取りの流れは[業務の情報の集め方](/companymap/docs/collecting)をご覧ください。聞き取りの基盤 CoeSignal（TechWorkerが開発・運用）の情報の取り扱いは、[CoeSignal Docs](https://coesignal.techworker.co.jp/docs/security) にも載せています。

## いまは対応していないこと

- SSO（シングルサインオン）
- 日本国内だけでの保存
- 第三者による脆弱性診断の結果のご提出

いずれも、必要なときは個別にご相談ください。対応できるかと、その時期は、ご相談のうえでお伝えします。
