## 稟議と予算

<ul class="check">
<li>対象にする範囲を決める（決まっていなくても、無料相談で一緒に決められます）</li>
<li>初期診断（14日）は一回の費用で、範囲に応じてお見積りします。秘密保持契約を結んでから始めます（当社のひな形をお送りします。御社のひな形でも構いません）</li>
<li>構築は業務ごとの固定額、運用は稼働中の業務ごとの月額です。初期診断で出した効果の試算と並べて、個別にお見積りします。席や人数ではいただきません</li>
<li>AIの利用料は御社のご契約のままです</li>
<li>最初に取り組む業務は、報告会で業務図と優先順位表を見てから決められます。報告会には、導入を決める方に出ていただきます</li>
<li>動き始めてからは、毎月の検証結果と月次報告で、任せた工程が基準を超えているかを報告します</li>
<li>やめるときは、業務図・AIエージェント・記録はすべて御社のものです。当社側のデータは30日で削除します</li>
</ul>

## 社内の運用

<ul class="check">
<li>窓口の方を1名決める</li>
<li>質問に答える方（その業務の担当者とベテランの方）に、質問票1時間・確認会2時間の時間をもらう</li>
<li>いまお使いの資料を共有する（新しく書く物はありません。一番新しい版を1つ）</li>
<li>社員の方への質問について、人事や労働組合への事前のご説明が要るかを確かめる</li>
<li>構築に進むときは、検証結果を見て任せる工程を承認する確認の担当を1名決める</li>
</ul>

事前のご説明には、[業務の情報の集め方](/companymap/docs/collecting)と[データの取り扱い](/companymap/docs/security)をそのままお使いいただけます。

## 情報システム

<ul class="check">
<li>ログイン：メールアドレスに届く確認コード（Cloudflare Access）。SSOは未対応です</li>
<li>使う端末：ブラウザだけで使えます。社員の方のパソコンにソフトを入れる必要はありません</li>
<li>保存先：Cloudflare D1・R2。保存時も通信時も暗号化。日本国内に限る設定はしていません</li>
<li>使うAIと経路：Anthropic Claude（Anthropic の API へ直接）、Cloudflare Workers AI（聞き取りの書き起こしと判定）、OpenAI（聞き取りの問いの読み上げ。送るのは問いの文だけ）。Anthropic と Cloudflare は、送った内容をAIの学習に使わない規約です。AIは資料から業務図の最初の下書きと工程の説明の空欄を直接書き、そのあとの変更は提案として出します</li>
<li>システムへの接続：初期診断の間は接続せず、書き出したファイルをお預かりします。構築のあとも、読み取り専用で接続するのは対象の業務の保存場所1か所です</li>
<li>構築のあと：AIエージェントが動く場所は、御社が契約中の環境（Microsoft 365・Google Workspace など）です。御社のAIの取り扱いは、御社の契約によります</li>
<li>他社事例の検索：データベースの中で並べ替えます。AIは使いません</li>
<li>Excel：ブックはブラウザの中で読み、保存するのは構造だけ。セルの値とマクロのコードは保存しません</li>
<li>操作の記録：画面の表示と変更・削除の操作を記録し、CSVで書き出せます</li>
<li>ログインのいらない入口：聞き取りの答える画面と、手順書をAIに読ませるURL（どちらも推測できない鍵付き）、他社事例の検索</li>
<li>削除：契約の終了時に、業務図・資料・記録と、聞き取りの答えを会社ごとまとめて削除（業務図などは復元用の履歴に最大30日、AIに送った内容は Anthropic 側に原則30日以内、規約に反する疑いがあると判定されたものは最長2年残ることがあります）。聞き取りの保管期間は契約で決めます</li>
</ul>

詳しくは[データの取り扱い](/companymap/docs/security)をご覧ください。

## 法務・個人情報

<ul class="check">
<li>聞き取りの同意：答える方の最初の画面で、取り扱いを示して同意を得ます</li>
<li>匿名の扱い：名前・連絡先は聞きません。最初の質問で役割を選んでもらい、同じ役割が5人未満なら役割を伏せます。取り込んだ答えは回答者の名前を付けずに保存しますが、本文に出てくる人名などは自動では伏せません。お客さまの画面には、答えの一文が業務図の根拠として出ます。完全な匿名とはお伝えしていません</li>
<li>録音：声は文字にするためだけに使い、録音は残しません。答えの保管の期間はご契約で決めます</li>
<li>処理を任せる会社：Cloudflare、Anthropic、OpenAI（聞き取りの問いの読み上げ）</li>
<li>使い道：聞き取りの答えは業務図をつくるために使い、人事評価には使いません</li>
</ul>

## 貴社の確認票について

社内のセキュリティの確認票（チェックシート）がある場合は、[無料相談](/companymap/contact)のときにお知らせください。このDocsにない項目は、個別にお答えします。
