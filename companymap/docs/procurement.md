## 稟議と予算

<ul class="check">
<li>対象にする業務を1つ決める（決まっていなくても、無料相談で一緒に決められます）</li>
<li>最初の2週間と、構築以降の費用は、対象の業務と範囲を伺ってお見積もりします</li>
<li>構築に進むかどうかは、業務図と改善候補の一覧を見てから決められます</li>
<li>効果は、浮いた時間を毎月記録し、役員向けの1枚で報告できます</li>
</ul>

## 社内の運用

<ul class="check">
<li>窓口の方を1名決める</li>
<li>聞き取りに答える方（その業務の担当者とベテランの方）に、1人15分ほど時間をもらう</li>
<li>聞き取りの案内を社内に配る（リンクと文面はこちらでご用意します）</li>
<li>社員の方への聞き取りについて、人事や労働組合への事前のご説明が要るかを確かめる</li>
<li>構築に進むときは、試す人を決める</li>
</ul>

事前のご説明には、[業務の情報の集め方](/companymap/docs/collecting)と[データの取り扱い](/companymap/docs/security)をそのままお使いいただけます。

## 情報システム

<ul class="check">
<li>ログイン：メールアドレスに届く確認コード（Cloudflare Access）。SSOは未対応です</li>
<li>使う端末：ブラウザだけで使えます。社員の方のパソコンにソフトを入れる必要はありません</li>
<li>保存先：Cloudflare D1・R2。保存時も通信時も暗号化。日本国内に限る設定はしていません</li>
<li>使うAIと経路：Anthropic Claude（Anthropic の API へ直接と、聞き取りの基盤 CoeSignal から）、Cloudflare Workers AI。いずれも送った内容をAIの学習に使わない規約です。AIは資料から業務図の最初の下書きと工程の説明の空欄を直接書き、そのあとの変更は提案として出します</li>
<li>他社事例の検索：並べ替えは TypeSafe 社のモデル（Cloudflare 経由で呼び出す第三者のモデル。Cloudflare の表示では、データを保持しないモデル）で、渡すのは検索の言葉と公開の事例だけです</li>
<li>Excel：ブックはブラウザの中で読み、保存するのは構造だけ。セルの値とマクロのコードは保存しません</li>
<li>操作の記録：画面の表示と変更・削除の操作を記録し、CSVで書き出せます</li>
<li>ログインのいらない入口：聞き取りの答える画面と、手順書をAIに読ませるURL（どちらも推測できない鍵付き）、他社事例の検索</li>
<li>削除：契約の終了時に、業務図・資料・記録と、聞き取りの録音・書き起こし・答えを会社ごとまとめて削除（業務図などは復元用の履歴に最大30日、AIに送った内容は Anthropic 側に原則30日以内、規約に反する疑いがあると判定されたものは最長2年残ることがあります）。聞き取りの保管期間は契約で決めます</li>
</ul>

詳しくは[データの取り扱い](/companymap/docs/security)をご覧ください。

## 法務・個人情報

<ul class="check">
<li>聞き取りの同意：答える方の最初の画面で、取り扱いを示して同意を得ます</li>
<li>匿名の扱い：名前・連絡先は聞きません。最初の質問で役割を選んでもらい、同じ役割が5人未満なら役割を伏せます。取り込んだ答えは回答者の名前を付けずに保存しますが、本文に出てくる人名などは自動では伏せません。お客さまの画面には、答えの一文が業務図の根拠として出ます。完全な匿名とはお伝えしていません</li>
<li>録音：会話を録音し、書き起こしと分析に使います。保管の期間はご契約で決めます</li>
<li>処理を任せる会社：Cloudflare、Anthropic（聞き取りの同意画面には、CoeSignal の別の機能で使う OpenAI も示しています）</li>
<li>使い道：聞き取りの答えは業務図をつくるために使い、人事評価には使いません</li>
</ul>

## 貴社の確認票について

社内のセキュリティの確認票（チェックシート）がある場合は、[無料相談](/companymap/contact)のときにお知らせください。このDocsにない項目は、個別にお答えします。
