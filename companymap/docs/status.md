## いま使える機能

| 機能 | できること | 使う人 |
|---|---|---|
| 業務図 | 担当・順番・使うツール・判断の分かれ目を1枚に。版の管理、コメント、直し方の提案。 | お客さま・実装担当 |
| 資料からの下書き | テキスト・PDF・ファイルから、AIが業務図の下書きを作ります。 | お客さま・実装担当 |
| AIの聞き取り | 共有リンクから、声か文字で答えます。答えを業務図に取り込みます。 | 設計と運用は実装担当。答えるのは社員の方 |
| AIに任せる順番 | 月の人の作業、浮く時間、最初に任せる3つと次の候補を出します。 | お客さま・実装担当 |
| 詰まりと施策 | 聞き取りで挙がった詰まりと、その直し方の施策を管理します。 | 実装担当 |
| 役員向けの1枚 | 浮く時間の見込みと実績、詰まり、施策、決めてほしいことをA4横1枚に。 | 実装担当が作り、お渡しします |
| 毎月の振り返り | 使われた回数と人が直した時間から、浮いた時間を計算します。 | お客さま・実装担当 |
| 作業ごとの手順書 | AIの作業手順・守るルール・AIにさせないことを、業務図から書き出します。 | お客さま・実装担当 |
| Excelの点検 | 壊れた数式・マクロ・ブックのつながり・入力の誤りを調べます。ブックはブラウザの中で読みます。 | お客さま・実装担当 |
| 他社のAI活用事例 | 公開情報から集めた4,864件の事例を探せます。 | どなたでも（[事例の検索](/companymap/cases)） |
| 操作の記録 | だれが、いつ、何を開き、何を変えたかを残し、CSVで書き出せます。 | お客さま（編集できる方）・実装担当 |

## 条件付きで提供するもの

- **業務の記録からの確認**：業務システムの履歴や画面の記録は、共有いただける形式に応じて、実装担当が読み込みます。自動で取り込む仕組みではありません。
- **社内のAIに手順書を読ませる専用のURL**：実装担当が発行し、いつでも取り消せます。発行と取り消しは操作の記録に残ります。
- **聞き取りの細かい設計**：聞く相手、質問、聞き返し方は、業務に合わせて実装担当が設計します。

## いまは提供していないもの

以下は、いまは一般には提供していません。予定の一覧ではありません。

- SSO（シングルサインオン）
- 日本国内だけでの保存
- 第三者による脆弱性診断の結果のご提出
- 聞き取り中の画面共有
- お客さまご自身による聞き取りの設計
- 業務システムからの履歴の自動取り込み
- 作業時間の自動の計測（浮いた時間は、入力した回数と時間からの計算です）

必要なときは、[導入前の確認事項](/companymap/docs/procurement)をご覧のうえ、個別にご相談ください。
