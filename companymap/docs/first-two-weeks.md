## 始める前に：30分の無料相談

30分のオンラインでその部署のお仕事を伺い、その場で1つの業務の流れを図にしてお見せします。

- 手元の資料があれば、その場で使います。資料がなくても、お話から図にできます。
- [相談のお申し込み](/companymap/contact)のあと、担当者より1営業日以内に、日程のご相談をお送りします。

## 14日の流れ

<ol class="steps">
<li><b>初日　秘密保持契約と、範囲・報告会の日を決める</b><span>当社のひな形をお送りします（御社のひな形でも構いません）。対象の範囲を決め、資料のお願いを1枚のリストでお渡しし、報告会の日を決めます。報告会には、導入を決める方に出ていただきます。</span></li>
<li><b>資料を読み、AIが下書きする</b><span>手順書・Excel・メールなど、お預かりした資料をAIが読み、工程・判断・例外の候補を下書きします。</span></li>
<li><b>8つの質問と確認会</b><span>資料で分からない点に絞った8つの質問に、質問票で1時間ほどでお答えいただきます。そのあと確認会（2時間）で、一緒に図を見て直します。</span></li>
<li><b>報告会　業務図・優先順位表・効果の試算をお渡しする</b><span>最初に取り組む業務を御社と決め、その場で開始日を決めます。効果の試算とあわせて、構築と運用のお見積りをお持ちします。</span></li>
</ol>

初期診断だけで終えることもできます。お渡しした業務図・優先順位表・効果の試算は、御社のものです。

## 8つの質問

| | 質問 | 分かること |
|---|---|---|
| 1 | 1件に何分？ | かかる時間 |
| 2 | 月に何件？ | 業務の量 |
| 3 | 誰が何人？ | 担当と人数 |
| 4 | やり直しは？ | 何件に1件か |
| 5 | 待ちは何日？ | 止まる所 |
| 6 | なぜそう判断？ | 判断が要る所と理由 |
| 7 | 時給は？ | 浮く額の元 |
| 8 | 何で測る？ | 効果の物差し |

6の判断の理由は資料に残りにくく、いちばん属人化しやすい情報です。

## ご用意いただく資料

新しく書く物はありません。いまお使いの資料を、そのままお預かりします。

| お使いの環境 | よくお預かりする資料 |
|---|---|
| Google Workspace | ドライブの手順書、Gmail の見積メール |
| Microsoft 365 | SharePoint の資料、Outlook のメール |
| kintone・販売管理 | 受注・見積の一覧を CSV で書き出したもの |
| Excel・紙の帳票 | 見積書・注文書の見本、手順書 |

- 一番新しい版を1つお預かりします。名前は伏せて構いません。
- 共有でも、書き出したファイルでも構いません。初期診断の間は、御社のシステムにつなぐ必要はありません。

## 対象にする範囲

「〇〇さんに聞かないと決まらない」仕事を含む業務を選びます。たとえば、見積、返金・値引きの判断、月次の数字がずれた理由の説明、納期が短い注文の受け方などです。

業務図1枚に載せる作業は10個までにしています。作業が多い業務は、2枚に分けます。どの範囲にするかは、無料相談か初日の打ち合わせで一緒に決め、初期診断の費用は範囲に応じてお見積りします。

## 報告会でお渡しするもの

- **業務図**：工程・担当・判断の基準・例外・AIの扱いを1枚にまとめたもの。製品の画面で管理し、同じ内容を御社の書式のPDFでもお渡しします。
- **優先順位表（Excel）**：工程ごとの浮く時間と効果額、御社のAI環境で動くか、推奨の理由。
- **効果の試算**：件数 × 1件の時間 × 時間単価で出した、工程ごとの効果。

それぞれの中身は[お渡しするもの](/companymap/docs/deliverables)をご覧ください。報告会のあとの進み方は[進め方と分担](/companymap/docs/how-it-works)にまとめています。
